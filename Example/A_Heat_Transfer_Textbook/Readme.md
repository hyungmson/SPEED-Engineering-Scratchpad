# SPEED inputs for A Heat Transfer Textbook, 6th ed.
This folder contains SPEED program inputs which solves problems of the textbook **A Heat Transfer Textbook, 6th** by J.H. Lienhard V and J.H. Lienhard IV (https://ahtt.mit.edu/).

- Usage
  - Download '{filename}.speed' file and open in SPEED program and do update to see the results.
  - {filename} corresponds to each chapter contents (ex. Chapter02.speed).
